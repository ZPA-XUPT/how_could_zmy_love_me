# 抛物线上的你--多线青春群像galagame

如果人生是一条函数曲线，
那上大学，大概就是它开始剧烈振荡的区间。

---

**抛物线上的你**是一款发生在西北工业大学的文字互动 galgame。
你扮演张明旸，一个爱数学、懂物理、怕社交的理工男——
高数题能一路推到无穷，
但自我介绍三句不到就开始卡壳。

某一天，生活突然开始“多解”：

* 在高数课堂上，把你从后排点到黑板前的，
  是传说中冷静到近乎刻薄的学霸学姐——**沈清岚**。
* 教学楼走廊里，追着稿件和话筒乱跑的，
  是笑得像广播 BGM 一样明亮的女孩——**林知夏**。
* 启真楼图书馆里，为了不挂科而一边喝奶茶一边拷问物理的，
  是脑子里随时在上演宇宙科幻的同学——**白可宁**。
* 报告厅里，用数据和曲线分析“人类选择”的，
  是把你叫作“有趣样本”的神秘学者——**叁捡柒**。
* 夜色操场上，安静陪你走圈、偶尔一句话就拆穿你伪装的，
  是看起来佛系、其实细腻的学长——**江临川**。

你的每一次“去 / 不去”、
每一句“算了吧 / 我试试”，
都会在这些人的世界里留下一个小小的偏移量——
好感度会改变，事件会分岔，
有人会走近，有人会远去，有些人则一直在原地等你回头。

这是一个没有超能力、没有救世任务的故事。
你要拯救的，只有那个本来打算一直坐在教室后排的自己。

在《抛物线上的你》中，
你可以推导极限，读深夜电台，和“数据疯子”讨论选择，
也可以在操场灯光下慢慢承认：
**原来被谁看见、选择靠近谁，
本身也是一道需要亲手作答的题。**
